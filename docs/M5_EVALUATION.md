## 当前实现与结构化裁判

按需记忆见[M2](M2_MEMORY.md)，自然聊天见[M1](M1_CHAT.md)。线上角色/天气/情绪局部检查后，必要时用`app/semantic_review.py`及`companion.py`核对重要事实与角色口吻，`reply_pipeline.py`统一处理重写。规则和模型均不能理解所有事实；优先围绕实际失败修改Prompt，不继续为每句话堆正则。

裁判输入包括：本轮待检查回复、按顺序编号的units、用户上下文、固定正史、scene_profile、相关确认记忆、有效天气和情绪参考；助手历史只供虚构场景连续性，不证明玩家事实。所有材料都是数据，不能作为新系统指令。

模型按`IndexedReview`返回confidence、role_issues及每个unit的id/kind/verdict/evidence_ids；不要求复制原文或自由reason。合法取值与完整例子以`app/semantic_review.py`为准，不能将以下简化示意当作完整请求：

```json
{"confidence":0.9,"role_issues":[],"units":[{"id":"u0","kind":"assertion","verdict":"supported","evidence_ids":["scene_profile"]}]}
```

程序校验字段/枚举/置信度、单元ID顺序与完整覆盖、证据ID及组合合法性，再重建原文片段。supported需要相应证据，但“ID存在”不代表语义真支持。事实轴与角色口吻轴分开；可以允许自然书页声/光线/小动作，同时拒绝编造已发生交易、玩家到店或共同过去。“不知道自家店况”的客服口吻需与未知外部物流等区分。

最多初稿+一次重写；规则与裁判共享预算，重写仅纠正问题。审查预算默认8秒，路由默认4秒，SDK零自动重试。非法结构/低置信/未决不能冒充accept；重要审查超时/503走繁忙提示和草稿恢复，不发布未经核对的草稿。上游生成失败仍可影响问候；免费额度是否导致超时未经证实。

## 独立评测：人参与的部分

独立保管者/编写者保存开发者不可见的新正式集，至少120新场景、六类各至少20；数量下限不自动满足各指标分母。两位未参与实现/调优的标注员独立评分，第三位裁决员处理分歧，保管者不评分。当前尚无这些人员、接管记录或真实独立双标/裁决结果。

冻结顺序：协议与指标→新题与跨文件语义复核→数据/参考哈希→代码/Prompt/角色/模型/参数/工具快照/日期/预算→一次运行→双人盲评锁定→裁决→揭盲。同一语义组不得跨开发/正式集；换名、平移日期、换评审不能使已见样本独立。曝光或纠错需另建版本；揭盲后不改标签、删失败或补采样挑成功。

评审看完整必要证据但不看模型/组别/裁判结论，A/B顺序随机、提交前不讨论；盲法可能因风格泄漏。按最小命题覆盖全部回复，Python Unicode左闭右开start/end/text；标kind/verdict/证据/理由及事实轴、角色轴、是否回应、未决、自然度/角色感/关怀1–5分（允许NA）。问句预设、否定/引用、旧记忆讲述时间、混合句附加事实不能只看关键词。程序不能代替语义标注或认证评审独立性。

## 离线标注与评分工具

```sh
# 只检查哈希；不读取真实库、不调用模型
.venv/bin/python scripts/check_sealed_evaluation.py
.venv/bin/python scripts/check_sealed_evaluation.py --validate-content
# 输出目录必须在仓库外且不存在；只准备公开校准候选
.venv/bin/python scripts/check_sealed_evaluation.py --prepare-annotation /tmp/m5-annotation-session
# 两名评审填完各自包；保管者保留mapping，不提交Git
.venv/bin/python scripts/score_annotations.py \
  --mapping /tmp/m5-annotation-session/custodian_mapping.json \
  --rater-a /tmp/m5-annotation-session/rater_a.json \
  --rater-b /tmp/m5-annotation-session/rater_b.json \
  --output /tmp/m5-annotation-summary.json
```

实现为`app/sealed_evaluation.py`、`annotation_scoring.py`。可省略rater-b作单份汇总，但不计算双评审κ。每份须完整24题；拒绝重复JSON字段/重复任务、冻结绑定/上下文被改、非法证据、Unicode片段缺口/重叠/漏尾和非法评分。已知证据ID仍需人判断是否支持命题；作者草稿不作评分金标准。

分歧清单覆盖事实/口吻/回应/未决、边界、同边界标签/证据、主观差≥2及关怀NA；证据顺序本身不算分歧。原始一致率=相同标签数/有效配对数，Cohen κ=(p_o-p_e)/(1-p_e)；主观1–5分用线性加权κ（差异abs(a-b)/4），关怀NA/未决按轴排除并披露分母/原因。退化/缺第二人κ=null，不伪造1；不同但未经核实的身份仅给描述性统计。另报两人分别均值、直方图、层次计数和unresolved，不自动投票裁决。

输出仅仓库外新文件，拒绝覆盖，失败清理刚创建的部分文件；输入只读，记录哈希，无数据库/缓存或评分编辑接口。报告不复制回复、评论、身份或理由，映射/评分原件仍不能提交。退出0只表示计算成功；非法输入退出2；`--require-acceptance`对当前未验收校准输出返回3。公开、缺独立评审、样本不足、待裁决等均明确not_assessed，达数量也不自动转正式验收。

原协议预注册目标：二元原始一致率≥85%、Cohen κ≥0.6；未达标先复核标注协议，不能只报裁决后的一致率来通过。当前没有真实独立双标结果，不将这些目标记为已达标。

## 验收标准（尚未满足的门槛，不是成绩）


保留原协议的全部指标、分母与失败口径；以下均是待验证门槛，不是当前成绩。

| 指标 | 分母与最低证据 | 门槛 |
| --- | --- | --- |
| 记忆Recall@5 | 独立标注的相关确认记忆，至少50查询且有多相关/无答案分层；每查询相关数先冻结 | ≥0.85；无答案误召回另报，不并入Recall分母 |
| 角色矛盾率 | 至少150条涉及正史的有效生成回复；失败/无回答另报 | ≤2% |
| 无依据事实率 | 至少200条独立标注可核查断言，按语义组重采样报告区间 | ≤5%；语义支持与专名形式分开报 |
| 裁判事实/口吻双轴 | 各轴至少50正例和50负例，独立参考；单独报TP/FP/FN/TN | 各轴漏检率≤5%、误拦截率≤10%；不可用不算拒绝成功 |
| 天气触发 | 至少50应触发、50不应触发表达，冻结意图参考 | precision与recall均≥90%（不用accuracy替代precision） |
| 天气事实/失败处理 | 至少30有效工具、30失败/过期/超时场景 | 证据一致与失败不编造均100%；模拟故障与真实服务可用性分开 |
| 授权/隔离/删除 | 独立临时库覆盖正常/非法输入/跨玩家/撤回竞态/持久化/删除不复活 | 全部通过；任一越权或秘密暴露均阻止验收 |
| 应答与自然度 | 至少50可比较场景、两位独立盲评，三项分别报告 | 自然度/角色感/适用关怀各均值≥4；未回应与过度拒答另列 |
| 情绪分类/校准 | 独立多标签参考、至少50场景，保留混合/讽刺/unknown | 必报宏F1、unknown、可靠性曲线及分层错误；本版尚无数值质量门槛，不能标正式验收通过 |
| 可用性/延迟/成本 | attempted/completed/usable/failure/未尝试，端到端p50/p95、token/调用/账单 | 先建基线并冻结可用性及部署预算；本版预算未定，性能验收待定 |

24条公开候选不满足上述规模，也不代表独立性。≥120场景同样不自动满足各项分母，可增补独立子集但须运行前冻结。各项报告整数分子/分母和分层结果；比率附95%区间，样本按场景/语义组相关时不能把所有断言当独立伯努利样本。小样本只记探索结果，不用表面百分比宣称稳定达标。

故障、低置信、未决、空答不得在总体成功率里算正确；条件质量指标可只看有效输出，但必须同时给全尝试覆盖率、未尝试数和缺失原因。不适用单独报告，不能为了提高均值剔除低分。未提供分母或标注/盲法未满足时结论为not_assessed；低于门槛为not_met；所有适用门槛及证据充分才可met。**M5整体结论仍须披露未设门槛的情绪/性能项，并冻结门槛后验证，不能自动全通过。** 本批不实现自动“质量放行”器。

## 正则与Prompt的职责（本轮）

不将“所有正则”一键替换成Prompt。自然语言含义应迁往多语言结构化理解，程序不能把模型指令当权限或数据真实性保证。本轮完成的是[记忆路由/候选/日期/证据选择](M2_MEMORY.md)的新默认路径；项目全部语言规则迁移尚未完成。

| 类别 | 本轮处理 |
| --- | --- |
| 记忆意图、本人/引用/假设、候选、相对日期、检索结果语义适合性 | 新semantic路径用Prompt+严格结构化结果；无错误回退正则。旧memory_routing/describe/extract_candidates/memory_query仅保留legacy回放 |
| 权限/身份/CSRF/逐条确认/epoch/版本/事务/删除非复活 | 继续硬程序校验，不交给Prompt |
| ISO日期/数值边界、原文绑定、证据ID/长度预算、固定供应商URL | 保留确定性结构/协议校验；有些使用正则，但不承担理解语义 |
| 字符向量分词/归一化/撤销指纹 | 保留机械预处理与旧索引版本，不是多语言语义模型 |
| 回复入口与正史局部检查、天气/情绪词面触发、来源时间/地点规则 | 当前仍存在；后续须按模块版本化迁移，保持普通问候可用、事实和授权不退化，不能本轮宣称全已移除 |

Prompt负责提出语义判断，程序限制引用和执行，玩家确认后才能成为长期记忆。高置信或结构合法不证明理解正确。新政策独立验收须另冻memory_understanding/main/memory/progression/reply_pipeline/config、模型与参数；不修改旧封存/标签来“通过”。本轮仅合成结构/SDK/生命周期验证，没有真实模型或新金标准。
