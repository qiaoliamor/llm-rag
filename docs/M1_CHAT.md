[中文](M1_CHAT.md) · [日本語](ja/M1_CHAT.md)

## 功能与设计

- 原创角色沈砚；固定身份、性格、正史与虚构书店环境分开配置。可以自然描写光线、声音、翻书、背景读者；不能借氛围捏造玩家经历、共同过去、具体交易/消息记录或真实天气。
- 默认`companion`使用简短Prompt，先接住当前话题，语气温和亲近；不强制每轮安慰、提问、自我介绍或绕回书店，不擅自建立恋人关系。
- 当前默认`companion`＋`REPLY_UNDERSTANDING_MODE=semantic`＋`REPLY_REVIEW_POLICY=contextual`：没有请求记忆/选证/天气/有效情绪上下文时，普通回复只生成一次，状态为`prompt_only`，不另调裁判。人设由角色卡和Prompt引导；涉及能力时仍走原校验/审查。`full`保留旧全量审查，`audit`保留审计流程；不能把普通回复称作已逐句验证。
- Gemini为默认后端，另有OpenAI和mock；OpenAI生成使用Responses API及`store=False`，分析工具通过结构化接口。外部503、限流和超时仍可能失败；网页显示温和繁忙提示，保留草稿供手动重试，不自动连续重采样。

PR #26以前的旧流程曾对几乎所有回复强制审查：生成问候成功仍可能因裁判超时变503。离线回归复现该路径后改为选择性核对；这证明程序路径，不证明某次玩家私有故障一定由它引起。

## 先让普通聊天自然可用（2026-11-24，PR #48交付）

按当前体验目标，问候、闲聊、角色背景提问和想被温柔陪伴的请求，无能力上下文时只调用一次生成。不会为每句话追加幻觉/逻辑裁判，生成失败仍保留温和繁忙提示；记忆/天气/有效情绪上下文与明确full模式仍使用原审查。本次未改角色正史、权限、逐条确认、撤回/删除或能力工具。

`companion.relationship_context`按服务器档位调整语气：0–29温柔好接近，30–59熟悉少客套，60–89自然关心/轻打趣，90–100可更像男友般陪伴。先接话、通常一两句，不每轮反问或给建议；不擅自宣布恋人关系。只发送档位风格文字，不发送分数/钱包/联系方式；能力仍按30记忆/60天气/90情绪资格并单独授权。低分/未送礼不冷淡。

Gemini固定四个合成场景实际4调用、全部HTTP200，端到端1.185–1.735秒，每次生成一次/裁判0/无重试，结果可用于本地体验。中文背景回答有“二十eight”夹词口误，原文保留，不挑样本；基本年龄/职业/开店背景没有改写。解锁/授权、礼物幂等、身份隔离和持久化通过离线回归，不声称本轮真实调用了记忆/天气/情绪工具。[原回复与命令](TEST_HISTORY.md#practical-companion-20261124)。正式质量/母语盲评保留为后续，本轮不开始M6。

现有.env不改；未配置REPLY_REVIEW_POLICY时使用新默认，显式full会保留旧路径。重启`./scripts/start.sh`后可在网页体验。
