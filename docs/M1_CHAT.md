# M1 · 角色对话与网页

状态：本地单角色闭环已交付；自然聊天改进PR #26、Gemini定向记录PR #27，成长界面PR #28。正式自然度/角色质量未验收。

## 功能与设计

- 原创角色沈砚；固定身份、性格、正史与虚构书店环境分开配置。可以自然描写光线、声音、翻书、背景读者；不能借氛围捏造玩家经历、共同过去、具体交易/消息记录或真实天气。
- 默认`companion`使用简短Prompt，先接住当前话题，语气温和亲近；不强制每轮安慰、提问、自我介绍或绕回书店，不擅自建立恋人关系。
- 普通“你好”和闲聊不强制调用第二个模型；确认记忆、天气/情绪证据及重要事实提示触发结构化核对。选择性入口仍是小规模启发式，不能保证发现全部复杂事实。历史`audit`模式保留作对照。
- Gemini为默认后端，另有OpenAI和mock；OpenAI生成使用Responses API及`store=False`，分析工具通过结构化接口。外部503、限流和超时仍可能失败；网页显示温和繁忙提示，保留草稿供手动重试，不自动连续重采样。

旧流程曾对几乎所有回复强制审查：生成问候成功仍可能因裁判超时变503。离线回归复现该路径后改为选择性核对；这证明程序路径，不证明某次玩家私有故障一定由它引起。

## 前后端入口

| 入口 | 职责 |
| --- | --- |
| `app/dialogue.py`、`app/companion.py` | 模型适配、角色Prompt、重要事实入口 |
| `app/reply_pipeline.py` | 本地检查、共享重写预算、回退 |
| `app/main.py` | `GET /v1/session`、`POST /v1/chat`、`DELETE /v1/session` |
| `frontend/src/App.tsx`、`api.ts`、`components/` | 会话、消息、草稿、清空确认、账户和解锁UI |
| `characters/` | 角色正史和场景底稿；不能以玩家输入改写 |

React + TypeScript迁移保留原书店风格和后端接口；主页只保留角色选择/个人账户，不展示开发计划，`/v1/project`已移除。隐私管理在账户内，解锁规则见[成长模块](RELATIONSHIP_GROWTH.md)。
