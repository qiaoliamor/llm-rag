# 日语版适配：设计、实现与待验证

[中文](JAPANESE_LOCALIZATION.md) · [日本語](ja/JAPANESE_LOCALIZATION.md)

日期：2026-11-11。基于PR #28功能和PR #29文档整理；**M5范围的语言适配，不是M6发布**。本轮真实API调用0次。

## 本轮已经实现

- 同一React应用切换中文/日本語，不复制前后端或另建玩家库。默认中文；选择保存在`persona.ui.locale`，只保存语言，不保存聊天/账户/分数；禁用localStorage时仍可用。
- 集中日语词典`frontend/src/locales/ja.json`及`i18n.ts`，覆盖角色选择、聊天、账户、礼物、隐私管理、天气依据、情绪设置、错误和解锁说明；同步HTML lang、标题、日语字体/断行和无障碍标签。繁忙/操作中禁止切换，避免在途请求语言混杂。
- 中文请求仍用原JSON；日语`POST /v1/chat`增加可选`locale:"ja-JP"`，仅允许zh-CN/ja-JP，非法值422。后端固定语言指令不接受客户端自定义Prompt；每次请求选择语言，不影响其他身份。切回中文时在当前会话明确切换。
- `app/localization.py`追加自然日语指令、提供明确标识的日语mock及确定性回退翻译。真实供应商原文照原样交付；不自动翻译旧聊天、玩家姓名/联系方式、记忆/城市/地名，不改角色ID和正史。沈砚显示为沈硯，28岁、栖川开店等事实不变，不据日语UI搬到日本或改身世。
- IME确认Enter不发送，提交后Enter才发送，Shift+Enter换行；继续保留失败草稿、手动重试、同UUID礼物幂等、30记忆/60天气/90情绪、解锁≠授权和既有数据删除入口。
- GitHub入口`README.md`/`README.ja.md`，模块中文在docs根、日语版在docs/ja，互相链接。日语页覆盖当前功能/设计/测试边界；旧原始合成回复、评分协议血缘、封存和权威AGENTS共享单份，不翻译或改写历史证据。以后语义变更同步双语页。

## 为什么日语适配不能只换文案

| 方向 | 当前边界 | 建议改进与验证 |
| --- | --- | --- |
| 口吻/文化 | 已加日语生成指令，但未真实验证自然度 | 日本语母语评审检查敬语/常体、称呼省略、距离感、不过度安慰/自称恋人；保持沈砚性格而非直译“男友模板” |
| 输入/排版 | IME、字体和换行做自动化；无设备实测 | 日文长标签、窄屏、键盘/读屏和不同IME人工抽查，Unicode字符计数/组合表情与前后端长度统一另评估 |
| 记忆提取/时间 | 中文保守提取与日期解析未变；日语可手动增查改删，事件日期可能未知 | 新增受控日语候选/主体/否定/引用/纠正/相对日期理解，再逐条确认；不将未知日期猜成有效日期 |
| 检索 | 768维字符哈希不等于日语语义嵌入，原字段识别偏中文 | 日语分词/表记揺れ/假名汉字、跨中日检索独立开发集；评估多语言嵌入并定义重建索引/迁移，不静默改旧向量版本 |
| 天气 | 日本城市覆盖不等于日本语意图/城市提取已适配；目前基线主要中文 | 解析「明日/明後日/週末/雨/傘/寒い」和都市/区县重名；仅显式城市，不取IP/GPS；按地点IANA时区，不由UI语言改时区；先Mock测触发/不触发/澄清/失败 |
| 情绪 | 结构化分析模型可接收日语，但中文自述/提前触发规则未扩展 | 日语省略/委婉/反讽/否定和最新自述优先的独立标注；低置信unknown、非诊断、支持手动纠正；不能拿中文F1当日语结果 |
| 事实审查 | 旧局部词面防线/选择入口偏中文，日语复杂重要事实可能漏检 | 优先日语生成/审查Prompt和结构化语义入口校准，不逐句堆正则。新增年龄/身世/玩家经历/来源时间/地名/到店预设双轴正反对，独立验证漏检/误拦截 |
| 数据与经济 | 语言切换不换身份/授权/钱包 | 维持原币种语义“デモコイン”，不显示成JPY/真实充值，不按日本语UI切换UTC额度日；正式账号/支付仍未实现 |

因此本轮是**日语UI和基础对话适配**，不是记忆/天气/情绪/事实审查的全面日语质量交付。日语页面在相关设置提示自动化能力仍待语言适配；不要宣称“检测到任意日语地名即可准确关怀”。手动记忆操作只证明原文保存/管理，不证明日语日期解析或召回质量。

## 验证口径

使用合成数据和独立临时SQLite，未读取真实玩家数据；前端Mock fetch/后端Mock模型和天气，无真实Gemini/Open-Meteo调用。

- 字典检查：所有已接入固定UI文案有日语项，插值占位符不丢失；不是模型翻译质量盲评。
- 前端：中文原契约、语言往返/持久化/存储受限、HTML语义、日语请求/CSRF、IME、保留原聊天/记忆、失败恢复且不自动重试、解锁说明/动效及删除确认。
- 后端：locale枚举、中文兼容、日语Prompt/切回中文、身份/CSRF、mock/回退、失败不计分不写历史、日语原文记忆CRUD/隔离/删除重启不复活。
- 本次没有新增库表、向量迁移、支付或外部缓存；这些增删改查不适用。数据库层/流水不变，PG233项沿用PR #28历史，不冒充本轮执行。

命令、耗时、首轮失败及结果统一见[TEST_HISTORY](TEST_HISTORY.md)。模型“原回复/耗时”本轮未采集，因为零真实调用；测试固定日语文本是合成fixture，不是Gemini效果成绩。旧原回复和失败仍保留，不重新采样挑成功。
