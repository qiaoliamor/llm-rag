- `pytest -q`：122 项通过，包括 100 个合成 mock 场景，以及输入校验、短期上下文、刷新与清空、跨会话隔离、CSRF、Host、请求体限制、会话过期/容量、并发保护、角色冲突重写与保守回退。
- 模拟 OpenAI SDK 响应：验证 Responses 请求携带 instructions、历史与 `store=False`；验证缺少密钥、认证失败、配额/限流、超时、网络错误、上游错误与空/不完整响应的中文错误提示。原始供应商错误及测试秘密不进入响应。
- `node --check app/static/app.js`：JavaScript 语法检查通过。
- `scripts/evaluate.py --limit 100`：direct、关键词 rag、完整 canon 三组 mock 链路各 100 条通过字面断言。Mock 不使用提示词进行推理，三组相同结果仅证明入口接通，不能用于比较效果。
- 本机服务 `GET /` 返回 HTTP 200；浏览器实测快捷话题填入、发送、角色回复、Enter 发送、多轮上下文、清空确认与恢复欢迎页。

- `.env` 位于忽略规则内，提交范围不包含密钥、真实聊天或运行数据库。
