更新日期：2026-11-02（Asia/Tokyo）。本文件汇总已确认的需求、设计意见、实际交付和未完成项；已合并基线 `ebb7318`（含PR #7状态更新规则），功能基线W01/W02为 `269fe98`；本次M4情绪支持闭环在独立任务分支实现，待PR审阅。

## 1. 目标与已确认意见

项目面向女性玩家的游戏角色互动，研究通过检索查询优化与提示工程，在保持角色人格和背景的同时减少无依据编造，提高自然度与个性化关怀。该目标仍需实验验证，不能从单次演示推导出“消除幻觉”。

| 用户诉求或设计意见 | 已确定的处理方式 | 当前状态 |
| --- | --- | --- |
| 记住重要个人经历和事件 | 长期记忆须带来源、主体、时间与授权，允许查看、纠正和删除 | M2 已实现确认式持久化记忆；网页支持查看/纠正/删除 |
| 天气关键词触发关怀 | 结合意图与城市、日期查询天气，避免把隐喻当请求，无结果不编造 | M3 已实现独立授权、地点/日期澄清、Open-Meteo与上下文投影，详见天气设计 |
| 多轮或必要时分析情绪 | 情绪视为带置信度的推测，玩家自述与纠正优先 | M4已实现独立授权、结构化推测、纠正及偏好；不等于真实心情或正式准确率结论 |
| 不破坏角色人格与过往 | 原创角色卡、固定正史、提示分层、输出检查与有限重写 | M1 已实现基础版，覆盖有限 |
| 先交付本地交互网页 | 单角色、中文、文本聊天，先完成可运行闭环 | 已完成 |
| 最初使用自己的 OpenAI API | 后端 Responses API 适配，密钥只在本地 | 适配完成并经模拟测试，尚未真实调用 OpenAI |
| 希望先用免费额度测试 | 查阅供应商资料后选择 Gemini，保留 OpenAI 和 mock | Gemini 已接通真实 API；不保证账号账单状态 |
| API 密钥不能上传 | `.env` 忽略、空模板、后端读取、响应不返回密钥 | 已落实并在提交前检查 |
| 开源并同步 GitHub | 公开仓库、MIT 许可证，只提交原创/授权内容及合成测试数据 | M3及W01/W02已通过PR合并至main（`269fe98`）；任务分支已清理，继续遵守AGENTS.md |
| 先整理文档，再开始 M2 前迁移前端 | 先完成文档整理及 React 迁移（`9141d46`），随后 M2 增加记忆后端与界面 | 已完成，保留原风格与功能 |

研究供应商时比较过 Gemini、Groq、OpenRouter 和 DeepSeek。最终只增加 Gemini 适配；其他服务没有接入。免费额度与供应商条款属于随时间变化的账号条件，不将研究结论固化为本系统保证。

## 3. 当前可运行状态

实际验证成功的本地配置为 `CHAT_PROVIDER=gemini`、`GEMINI_MODEL=gemini-3.5-flash-lite`。密钥值不记录在文档中。

M2 已将源码配置、`.env.example` 和断言统一为 `gemini-3.5-flash-lite`。此前默认值为 `gemini-2.5-flash-lite`。真实请求证明该旧模型不向此次新账号开放；本地 `.env` 覆盖后才成功。F01 已完成，用户已有密钥保持不变。现有 `.env` 用户不应被启动脚本自动覆盖。

已验证命令为 `./scripts/start.sh`，访问 `http://127.0.0.1:8000/`。React 构建发布到原 `app/static/`，原服务可通过刷新加载；新启动会先自动完成前端构建。运行环境增加 Node.js 22.12+ 和 npm。
