## 3. 针对性代码完善

### F02：未知背景的失忆解释

`conflicts(reply, query)` 现在接收当前问题；涉及童年/小时候/父母/亲属时，有限检查第一人称或“那段记忆/经历”的“记不清、不太记得、不记得、忘记了、没有留下痕迹”等解释。聊天首次检查与重写后检查都带当前问题；命中后沿用最多重写一次、仍失败保守回退，并只把最终安全回复加入历史。

合成回归：问“你小时候和父母住在哪里？”，首答“我不太记得小时候住哪。”应被拦截；重写为“我不知道，不能随口补写。”则接受，重写仍失忆解释则回退。非背景问题及被引号包裹的用户原话有反例检查。这是词面修复，不声称能识别所有无依据背景或复杂省略句。

### F03：404错误提示

Gemini/OpenAI共享生成适配器单独捕获SDK NotFoundError，返回 `model_unavailable`、HTTP503，提示核对本地模型名、接口地址及账号权限后重启；不暴露上游原文、密钥，也不自动切换模型或mock。404不一定是模型停用，所以提示不作此断言。真实SDK内存HTTP transport覆盖Gemini404；OpenAI错误适配有合成异常回归。未新增真实API请求。

### F04：部分否定、引用、主体与中文年龄

增加中文年龄检查，接受28/二十八，拒绝19/二十九/三十等；明确归属他人或被否定的引用不作为角色自述；单纯把自己的错误回答包在引号里仍会被检查，第三人称年龄/职业不误当本人；继承规则排除部分否定与第三人称，并按转折分句避免前一句否定掩盖后一句肯定。额外补充仅用引号包裹错误年龄/职业的防绕过回归。F04仍未整体勾选完成：不支持通用指代消解、所有中文数字/否定范围或引用语义，可能漏判或误判，需继续扩展对抗和真实模型评测。

通过AST从 `90350e4:app/dialogue.py` 提取旧conflicts函数，与当前版本对同一15个开发正史案例作有限规则对照：旧8/15，新15/15。旧失败ID为canon-04、05、12、14、16、17、18。两组未调用生成模型，不能把这个比例当无依据事实率下降。
