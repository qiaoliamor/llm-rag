# 日本語版：設計・実装・残る検証

[中文](../JAPANESE_LOCALIZATION.md) · [日本語](JAPANESE_LOCALIZATION.md)

2026-11-12。PR #29/#30/#31はマージ済み、今回もM5内の言語対応です。M6には進まず、実APIは0回です。

## 今回の実装

- Reactを複製せず、中国語／日本語を同じ画面で切り替えます。初期値は中国語。localStorageの`persona.ui.locale`には言語だけを保存し、利用できない環境でも切替は動作します。
- `frontend/src/i18n.ts`と`locales/ja.json`で画面文言、アクセシブル名、確認・失敗・解放の説明をまとめます。HTMLのlang、タイトル、フォント、禁則と折り返しにも対応します。
- 日本語リクエストだけ`POST /v1/chat`に`locale:"ja-JP"`を指定します。中国語は以前のJSON形式を維持します。バックエンドの選択肢はzh-CN/ja-JPだけで、不正値は422です。処理中は切替を止め、他のユーザーの言語や許可には影響させません。
- `app/localization.py`の固定指示で落ち着いた自然な日本語を求めます。日本語のオフラインデモと既定フォールバックを用意します。実モデルの返答はそのまま渡し、過去の会話、記憶、連絡先、地名は自動翻訳しません。
- 沈砚の画面表記は沈硯。ID、28歳、栖川の古書店、背景は変えません。日本語化を理由に日本へ移住させたり恋人関係を作ったりしません。
- IMEの確定Enterでは送信せず、確定後のEnterで送信、Shift+Enterで改行します。失敗時は下書きを戻し、連続再試行しません。30/60/90の資格、個別許可、削除、デモコインの意味は共通です。
- READMEとdocsを中国語／日本語で案内します。過去の生の合成応答、失敗、凍結資料、正式なAGENTSルールは共有し、翻訳で書き換えません。

## 検証と次の順序

合成データ、独立した一時SQLite、Mock fetch／モデル／天気だけを使います。辞書と変数、言語往復、保存不可、IME、原文保持、CSRF、不正locale、解放と個別許可、失敗・下書き、記憶CRUD・隔離・削除後の再起動を検証します。結果と失敗は[テスト記録](TEST_HISTORY.md)にまとめます。

今回、実Geminiの原応答や所要時間は採取していません。固定日本語応答はテストfixtureです。既存の実験・失敗を消したり、成功するまで再サンプリングしたりしません。テーブルやベクトル、決済、外部キャッシュを変更しないため、それらの新規CRUD・移行は対象外です。

次は口調・用語と開発用正反対例を固定し、記憶ルーティング／抽出、天気意図／日付、気持ちの自己申告を個別に対応します。その後、新しい日本語・日中横断の独立データと評審を用意します。localization/companion/main/pipelineの新ポリシーを別途固定し、旧封存v1/v2は変更しません。実APIは今後、対象と上限を明示した旧失敗の少数再検証だけにします。M5全体の品質、費用、M6は未完了です。

PR #29の文書整理は5a62fcaへsquash済みです。PR #30の基本日本語対応を本回squashでmainへ提供します。日本語の独立品質とM5は未受入、M6は未着手です。
