# M3 · 天気に合わせた気遣い

[中文](../WEATHER.md) · [日本語](WEATHER.md)

## 機能・データフロー

親密度60に達しても自動ではオンにならず、個別許可が必要です。明示した都市または保存した都市だけを使い、IP/GPSや記憶から居場所を推定しません。重名・不明な都市や曖昧な日付は確認します。現地IANA時区の現在推定と7日間の1日予報に対応し、一時的な行き先は保存済み都市を変更しません。

実装はapp/weather.py、画面はWeatherPane.tsx／WeatherEvidence.tsxです。Open-Meteoの地名search/getとforecast固定HTTPSを利用します。現在の採用は非商用無料エンドポイントでキー不要ですが、商用化前に現行条件を再確認します。これは2026-11-01の採用記録であり最新の料金保証ではありません。

モデルへ渡すのはstatus、場所／時区／日付／kind、必要な温度・体感・現在湿度・降水・風・状態とdemoだけです。欠けた数値を補わず、未来に現在湿度を転用しません。source、署名、取得時刻、有効時刻、キャッシュは根拠UIへ別渡しし、原JSONを注入しません。

## 自然な返答・失敗・管理

W01：現在値はモデル推定で地上の実測ではありません。UIに性質を明示し、台詞では自然に「だいたい」などを使います。W02：予定に合わせた短い気遣いにし、提供元／日付の読み上げやカスタマーサポート口調を避けます。虚構の窓辺から実際の天気を断定しません。

HTTP5秒、再試行なし。キャッシュは公開天気だけ、600秒／128件、currentの有効時刻が90分超なら使いません。設定変更・削除で許可と旧応答を失効させます。進行中リクエストが公開キャッシュを埋めても削除済み本人設定は復活しません。

GET /v1/weather/settings、GET /v1/weather/locations、PATCH/DELETE /v1/weather/settings。本人／同源／CSRFを検査し、ロック中も停止・都市削除はできます。失敗には古い温度を付けず状態だけ返し、実サービス失敗を偽天気に置き換えません。
