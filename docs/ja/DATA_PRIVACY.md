# データとプライバシー

[中文](../DATA_PRIVACY.md) · [日本語](DATA_PRIVACY.md)

情緒返答審査は現在のモデルを再利用し新規業者は増やしません。必要ラベル／出所／信頼度・basisまたは推定強度だけ投影し、元情緒証拠ID／時刻・自己申告強度の仮値は除きます。言語／有効希望／状態は別emotion_policyで心理証拠に使用不可。オフなら旧参考は送らず、追加保存／長期記憶書込はせず許可・epochを維持します。

情緒semanticは90点＋個別許可後、毎ターン原文／ID・有限短期窓と現参考labels/sourceを送信し、申告／信号を理解します。完全推定は間隔／冷却で制御し、両段階で既定6秒共有・再試行なし。原文引用を追加保存せず、解釈はsource=model+basis=self_report、source=userは手動訂正のみ。本輪希望は設定へ保存せず、失敗では旧モデル結果を注入せず、手動訂正は閲覧用に残せます。窓に本人が書いた事実は含まれ得ますが、連絡先／長期庫／工具snapshotは別途取得しません。[情緒設計](EMOTION.md)へ。

中日semantic天気理解は60点と個別許可の後、現在の原発言と有効な確認待ち日付構造だけを現在の対話モデルへ送ります。長期記憶・連絡先・助手履歴・保存都市は含めません。不明／失敗では天気取得せず、旧ルールへ戻しません。文字・原文検査は意味の正しさを保証しないため独立検証は残ります。地名提供者へは都市名だけ、予報へは座標／時区だけです。

- 短期会話はサービスメモリの直近12往復で、再起動で消えます。完全な会話ログはDBへ保存しません。本人が確認した記憶原文と候補はローカルDBに残ります。
- 記憶／天気／気持ちは30/60/90の資格に加え個別許可が必要です。解放や言語変更だけで許可・取得・保存を開始しません。オフでも既存データの確認・削除・許可取り消しができます。
- 記憶削除は原文とベクトルを除去し、非テキストの操作メタデータと本人塩付き指紋を残して自動復活を防ぎます。暗号化・完全匿名化とは違います。最新変更のepochで処理中応答を撤回します。
- 天気検索は都市名、予報は座標／時区だけを外部へ送ります。IP/GPSによる位置推定はしませんが、提供者は検索地点とサーバーIPを知り得ます。キャッシュは公開天気だけで個人IDは含みません。
- 気持ちの追加分析は許可した最近の会話を現在モデルに送ります。推定・原分析は会話内一時保持で、長期ラベル化しません。設定と本人の好みだけ保存します。
- モデルへは役柄、最近の会話、今回入力、必要な確認記憶とツール投影を送ります。APIキー、全記憶庫、プロフィールの連絡先を自動で渡しません。供給者の保持条件や無料枠は本アプリでは保証しません。
- 言語だけをlocalStorageのpersona.ui.localeに保存します。切替で会話／記憶／名前／地名を書き換えず、新IDを作りません。Cookie消去後の復旧はありません。
- プロフィール消去は名前・メール・電話だけです。財布・ポイント・冪等履歴を含む正式なアカウント削除と留存方針は未実装です。ウォレットはデモで請求しません。
- .env、キー、DB、ログ、実ユーザー会話、記憶、評審原本や実行エクスポートはGitに出しません。PGは本機54329、アプリ内暗号化やバックアップ消去、複数端末復旧、正式監査は未実装です。

別タブの表示済み旧文言は再読み込みが必要です。公開に必要な正式ログイン、完全アカウント削除／バックアップ留存と削除、多インスタンスは今後の課題で、M6未着手です。詳細な既存ポリシーは[中国語原文](../DATA_PRIVACY.md)、日本語実装範囲は[言語対応](JAPANESE_LOCALIZATION.md)にあります。

## 意味記憶の追加データフロー

semanticかつ資格／個別許可が有効なら、毎ターンの原文、最大12件の短期メッセージ、本人時区と当地日付を現在モデルへ送り、DB検索の必要性を先に判断します。必要なときだけ本人の確認済／有効な文字候補最大20件のid/fact/event_dateを同じ提供者へ送り選択し、最大5件／1200文字を生成へ渡します。全記憶の直接送信や毎回のDB検索ではありません。

手動追加／修正もその原文をメタデータ解析へ送ります。変更なしの確定では追加呼出しません。解析結果は要求内の一時情報で、検証済み候補原文と既存メタデータだけを成功後保存し、本人の個別確認を待ちます。失敗時の再試行／正規表現代替はなく、手動保存は日付不明で可能です。無効／未解放は呼出を止め、epochで処理中の書込みを撤回します。すでに供給者が受け取った内容の消去は保証できません。埋め込みは引き続きローカルです。

既定返答semanticは自由応答・必要な本人文脈・正史／場面・選択済確認記憶・今回のツール参考を同じ設定モデルへ審査送信します（他の照合不要な完全一致信頼短句を除く）。記憶の追加検索や解放／許可の変更はせず、reply_policyはlocaleのみ。助手履歴を本人事実へ昇格しません。新たな保存／ログ／表／第三者はなく、呼出頻度と実費用は未受入です。
