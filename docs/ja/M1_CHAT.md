# M1 · キャラクター対話と画面

[中文](../M1_CHAT.md) · [日本語](M1_CHAT.md)

## 機能・設計

沈硯という同一の架空人物と会話します。基本設定と古書店の場面設定を分け、穏やかな親しみは許しつつ、恋人関係・共有した過去・プレイヤーの経験を作りません。光や音、ページをめくる普通の仕草は物語の表現として許容します。

Gemini/OpenAI/mockに対応し、companionの短い指示で今の話を受け止めます。既定REPLY_UNDERSTANDING_MODE=semanticでは、根拠／強制照合なしの完全一致した信頼済み挨拶短文だけを直接返し、他の自由応答は共通の意味審査で最大1回書き直します。中文キーワード入口と人物／時刻／地名の局所判定を使わず、追加の選択器呼出もありません。legacyのみ旧経路を再現します。実遅延・費用と漏検は未受入です。[M5](M5_EVALUATION.md)を参照してください。

トップはキャラクター選択／アカウント。開発計画はプレイヤー画面に出しません。日中切替は表示の選択で、履歴と本人のデータを勝手に翻訳しません。IME確定Enterは送信しません。サービス失敗は穏やかな混雑案内と下書き復帰で扱い、勝手に連続再試行しません。

## 実装・検証

app/dialogue.py、companion.py、reply_pipeline.py、localization.pyとfrontend/src/が入口です。GET /v1/session、POST /v1/chat、DELETE /v1/sessionを使用します。日語のlocale追加は任意で、以前の中国語JSONも使えます。

PR #26時点では22個の明示companion回帰、全体886通過／26スキップ。旧auditを含む全数を新既定経路の検証と数えません。PR #27の中国語合成2入力は各1回、1.124秒／5.625秒で返答しました。独立ブラインド評価、男友らしさ、一般的可用性の証拠ではありません。原文は[履歴](TEST_HISTORY.md)に共有します。

今回の日本語はMock／固定fixture検証のみで、実モデルの自然さや母語話者の評価は未実施です。旧503、timeout、未検証項目を保留し、M6には進みません。

日語口調はshen-yan-ja-care-v2へ。旧Promptを保持し、常体／呼称省略／傾聴と雑談の設計、12編集校準文・母語人評待ちは[日本語対応](JAPANESE_LOCALIZATION.md)へ。実モデル前後比較なし、自然さ向上は未実証です。
