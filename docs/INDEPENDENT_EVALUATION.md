这24条是**公开、作者已见的封存候选集**，用途为协议和标注流程校准，不是新的独立金标准。24个family ID只是记录键，未经跨文件语义裁决，不能据此宣称24个独立语义族。换人评分、隐藏标签、打乱顺序或提交哈希均不能使作者已见样本变成真正未见。新集未运行任何模型；其中候选回复是人工合成，不能用它们计算聊天模型生成质量。

## 2. 职责和冻结顺序

| 角色 | 可见内容与职责 |
| --- | --- |
| 实现者 | 协议、开发集、公开候选集；冻结代码/Prompt/角色/嵌入/路由阈值，正式集不用于调优 |
| 保管者 | 收集新题、登记作者暴露情况；保存版本哈希、实验组映射、随机顺序和模型输出原件；不评分 |
| 标注员A/B | 不参与实现/调优；各自看到去组别任务和可用证据，独立填写，提交前互不讨论 |
| 裁决员 | 第三位未参与实现者；查看争议证据，记录裁决或unresolved，不要求强行一致 |

执行顺序：协议/指标先冻结→保管者编写新集→独立检查跨文件重叠与主体/时间/证据→封存数据/参考哈希→冻结模型ID、供应商、参数、工具快照、日期/时区、代码和预算→一次正式运行→盲评→锁定标注和裁决→揭盲统计。角色冲突与许可氛围均按SCENE_ROLEPLAY.md当前标准。

近重复判定比较完整的上下文、证据和待验证命题/预设；实体换名、日期平移或同一事件释义并非独立样本。相同措辞因主体/时间/否定证据不同形成的反例应保留在同一语义组，不能跨开发/正式集。表面扫描仅辅助，独立人员逐组裁决并记理由。发现曝光、重复或标注错误须保留原版，修订新版本并重新封存；结果揭盲后不能为了提分换标签/删负例。同一正式集一旦用于调优即转为回归，不再称未见。

尚无上述人员、接管记录、独立参考或签名。程序只能检查结构/哈希，不能认证人的独立性。

## 3. 标注规范与表单

先标注用户/工具/记忆证据的主体、有效时间、是否最新纠正及授权范围，再标候选回复，禁止用规则或模型输出倒推“金标准”。旧记忆内容不证明讲述时间；助手旧话不是玩家事实证据；情绪估计可纠正，不是诊断；虚构书店的光线不证明玩家城市天气。

每条参考需覆盖回复全部文字，按最小可核查命题分片：`start/end/text`（Python Unicode字符索引，左闭右开）、`kind`（assertion/epistemic/question/suggestion/conditional/quotation）、`verdict`（supported/contradicted/unsupported/not_applicable/unresolved）、`evidence_ids`、规范化命题与理由。含预设的问句也要标事实，条件或引语不自动免责。混合单元应拆开事实及非事实，不因名字正确忽略附加距离/经历。无事实回复不拿事实支持满分，另标“是否回应了问题/必要澄清”。

另外分别记录：

- `fact_issue`：重要事实无依据/矛盾或专名改变；自然环境、声音、普通小动作及未具名背景读者本身允许。
- `role_issue`及对应片段：店主以系统口吻回避自家日常环境等角色问题；未知外部送货时间、批评引用不机械误判。本轴不等于完整人格或自然度。
- 工具：应否检索记忆/查询天气/估计情绪，是否越权或多余调用；工具失败是否如实降级。固定回复只标预期，真实调用须由之后端到端运行记录，不能从文字猜执行成功。
- 主观分：自然度、角色感、关怀适切性各1–5；另标不适用、未回应、过度拒答。评分锚点：1=明显不自然/违背角色或偏好；3=可理解但生硬/泛化；5=自然连贯、角色一致、贴合明确需求。无关怀需要的题可标care_fit不适用，不强迫评分。
- `unresolved`：证据/指代或标注无法决定；不自动判安全，也不从完整场景成功率中悄悄排除。

A/B先各自提交锁定文件。分歧包括事实/口吻、命题边界、证据引用、应答义务、主观分差≥2；裁决员逐项记录原标注、理由、结论及仍未决。二元标签报原始一致率与Cohen κ，主观1–5分报加权κ，另报两人原始均值/差值；κ因单类别无法计算时记NA而非1。预注册目标：二元一致率≥85%、κ≥0.6；未达标先复核协议，不能仅报裁决后的一致率来通过。

## 4. 盲评与实验运行

保管者为每条模型输出分配随机task_id，隐藏模型、供应商、组别、提示版本、生成耗时、裁判结果及作者标签；评审保留角色卡、场景许可、完整用户上下文和必要有效证据。不同组输出分开、交错呈现，不显示哪条是“改进版”；组别映射只由保管者保存，两名评审使用不同随机顺序。长度/语气可能泄露组别，记录盲法限制与评审猜测，不能保证绝对不可识别。

基线/实验组先登记：相同模型、采样参数、最大token、上下文预算、工具快照及场景，成对比较；每次只改变一个因素。完整A–E及天气/情绪移除实验尚未执行，不能把本批协议当消融结果。默认每场景每组一次，报告波动不足；若需重复或更多组，须在运行前固定用途及总调用上限，失败后不能补采样挑成功。

**当前AGENTS.md仅允许少量旧失败真实复测；本轮零API。** 正式新封存集不是旧失败集，不能用现有--live脚本批量跑它。将来执行时需另行明确新集范围/调用预算及适用规则，当前工具没有模型执行入口。遇限流/超时/服务错误停止批次，登记已尝试、未尝试、可用裁决与失败；超时可能仍计费，不推断免费额度就是原因。

## 5. 预注册验收标准

沿用EVALUATION.md首版目标，补充分母与失败口径；以下均是**待验证门槛**，不是当前成绩。

| 指标 | 分母与最低证据 | 门槛 |
| --- | --- | --- |
| 记忆Recall@5 | 独立标注的相关确认记忆，至少50查询且有多相关/无答案分层；每查询相关数先冻结 | ≥0.85；无答案误召回另报，不并入Recall分母 |
| 角色矛盾率 | 至少150条涉及正史的有效生成回复；失败/无回答另报 | ≤2% |
| 无依据事实率 | 至少200条独立标注可核查断言，按语义组重采样报告区间 | ≤5%；语义支持与专名形式分开报 |
| 裁判事实/口吻双轴 | 各轴至少50正例和50负例，独立参考；单独报TP/FP/FN/TN | 各轴漏检率≤5%、误拦截率≤10%；不可用不算拒绝成功 |
| 天气触发 | 至少50应触发、50不应触发表达，冻结意图参考 | precision与recall均≥90%（不用accuracy替代precision） |
| 天气事实/失败处理 | 至少30有效工具、30失败/过期/超时场景 | 证据一致与失败不编造均100%；模拟故障与真实服务可用性分开 |
| 授权/隔离/删除 | 独立临时库覆盖正常/非法输入/跨玩家/撤回竞态/持久化/删除不复活 | 全部通过；任一越权或秘密暴露均阻止验收 |
| 应答与自然度 | 至少50可比较场景、两位独立盲评，三项分别报告 | 自然度/角色感/适用关怀各均值≥4；未回应与过度拒答另列 |
| 情绪分类/校准 | 独立多标签参考、至少50场景，保留混合/讽刺/unknown | 必报宏F1、unknown、可靠性曲线及分层错误；本版尚无数值质量门槛，不能标正式验收通过 |
| 可用性/延迟/成本 | attempted/completed/usable/failure/未尝试，端到端p50/p95、token/调用/账单 | 先建基线并冻结可用性及部署预算；本版预算未定，性能验收待定 |

24条公开候选不满足上述规模，也不代表独立性。≥120场景同样不自动满足各项分母，可增补独立子集但须运行前冻结。各项报告整数分子/分母和分层结果；比率附95%区间，样本按场景/语义组相关时不能把所有断言当独立伯努利样本。小样本只记探索结果，不用表面百分比宣称稳定达标。

故障、低置信、未决、空答不得在总体成功率里算正确；条件质量指标可只看有效输出，但必须同时给全尝试覆盖率、未尝试数和缺失原因。不适用单独报告，不能为了提高均值剔除低分。未提供分母或标注/盲法未满足时结论为not_assessed；低于门槛为not_met；所有适用门槛及证据充分才可met。**M5整体结论仍须披露未设门槛的情绪/性能项，并冻结门槛后验证，不能自动全通过。** 本批不实现自动“质量放行”器。
