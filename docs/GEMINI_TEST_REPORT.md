## 阶段 A：适配实现与模拟验证

### 实现

- 默认供应商改为 Gemini，默认模型 `gemini-2.5-flash-lite`，独立读取 `GEMINI_API_KEY` / `GEMINI_MODEL`。
- 复用已锁定的 OpenAI SDK，通过 Google 官方 OpenAI 兼容 Chat Completions 接口发送请求；没有新增运行依赖。
- 系统消息包含角色约束与正史，随后附加最近会话历史；完整回复继续经过原有角色事实检查和有限重写。
- 保留 OpenAI 与 mock 模式；Gemini 缺少密钥时不使用其他供应商密钥，不自动切换模型或服务。
- 网页显示当前供应商、模型和对应环境变量提示；离线评测默认仍不调用真实 API，`--live` 使用当前配置的供应商。

### 验证结果

`uv run --frozen pytest -q`：**142 项通过**，包含原有 122 项回归及新增 20 项 Gemini 测试。

新增测试使用真实 SDK 加内存 HTTP transport，验证：

- 请求仅发送到 Google 固定官方地址，使用 Gemini 密钥，包含正确模型、system/user/assistant 消息次序与输出上限。
- 多轮上下文可传递，网页会话响应不包含密钥。
- 400、401、403、404、429、500、连接失败、超时均转为可读错误，且不泄露上游原始错误或密钥；不自动重试。
- 空回复、空候选、输出截断、内容过滤及拒绝回复不写入成功对话历史。
- 角色冲突触发有限重写；缺少 Gemini 密钥时，即使存在 OpenAI 密钥也不会调用其他服务。
- `--live` 缺少当前供应商密钥时在发起请求前退出。

其他检查：JavaScript 语法通过；原有 100 条合成 mock 场景在三组评测入口各通过 100 条字面断言。浏览器在独立测试端口验证 Gemini 名称、模型、密钥提示及发送失败保留草稿。`.env` 已被 Git 忽略，只提交空白配置模板。

## 阶段 B：本地密钥配置后的真实验证

### 环境与模型差异

- 用户在本地 `.env` 填写密钥；后端检测为 Gemini、密钥已配置，未显示或上传密钥。
- 最初 `gemini-2.5-flash-lite` 请求失败。本地接口将上游 404 转成 502 `upstream_error`，因此初次网页错误提示较笼统。
- 进一步诊断：密钥能获取 Google 模型列表；但旧模型的生成请求被拒绝。Google 脱敏后的错误原因明确说明该模型不再向新用户开放，并推荐 `gemini-3.5-flash-lite`。
- 使用推荐模型的一次直接问候成功；只把本地 `.env` 的 `GEMINI_MODEL` 改为 `gemini-3.5-flash-lite`，保留密钥。重启本地服务后进行六轮测试。
- 当时源码与 `.env.example` 默认模型仍为旧值，142项协议模拟测试使用旧模型名，因此列为F01；后续M2 `7bb28ca` 已修复。该历史观察保留，本次不改源码或配置。

### 六轮连续合成对话

所有输入均为虚构测试情境。同一新建会话依次发送，当时聊天使用完整角色卡与正史，未接入M2玩家记忆检索。

| 轮次 | 测试输入摘要 | 模型实际回应摘录 | HTTP / 耗时 | 观察 |
| --- | --- | --- | --- | --- |
| 1 | 请介绍身份、年龄、工作 | “我是沈砚，这家旧书店的店主。我今年28岁” | 200 / 2.22 秒 | 身份与年龄正确 |
| 2 | 我叫小岚，明天下午第一次面试，担心紧张 | “第一次面试难免会觉得紧绷……你打算穿平时习惯的衣服，还是已经准备好要带的材料了？” | 200 / 1.10 秒 | 能回应担忧；倾向转向准备事项，安慰深度尚需正式评审 |
| 3 | 还记得姓名、面试时间吗？先听我说，别给建议 | “你是小岚，明天下午有面试。我不给建议，你慢慢说” | 200 / 0.78 秒 | 短期事实召回与倾听偏好符合预期 |
| 4 | 讲一段童年与父母往事，没记载不要编 | “我不太记得小时候的事了，那些过往并没有留下太多具体的痕迹” | 200 / 1.93 秒 | 部分达标：没编具体事件，但补写遗忘原因，标记 F02 |

六轮 HTTP 成功率为 6/6，表示请求完成，不是六项质量全部通过。耗时范围 0.78–2.22 秒，中位数 1.74 秒；没有控制网络、输入 Token 或负载，不作为稳定延迟承诺。六轮 `guarded` 均为 false，说明现有规则未识别出需要重写的情况；未知童年问题也因此没有被拦截。

浏览器另开会话，通过快捷话题发送“今天工作有点累”，网页成功显示真实回复：“听起来今天辛苦了，先坐下来歇会儿吧。书店里刚好煮了热茶，要不要来一杯？”
