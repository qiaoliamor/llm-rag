# 心语 · Persona RAG

面向女性玩家游戏的个性化角色对话系统：通过可追溯记忆、受约束的检索增强生成（RAG）和提示工程，让角色记住玩家、关心当下，并保持稳定的人格与背景。

**当前状态：项目规划阶段。尚未实现服务、接入 API 或验证效果。**

## 核心功能

- **长期记忆**：提取玩家明确表达的重要经历、事件和偏好，支持查看、纠正和删除。
- **天气关怀**：通过天气相关关键词与意图触发查询，使用玩家选择的城市生成有事实依据的关怀。
- **情绪支持**：结合多轮上下文估计情绪及置信度，用符合角色的方式回应，并接受玩家纠正。
- **角色一致性**：区分不可改写的角色正史、关系状态与玩家记忆，降低无依据编造和设定冲突。

本项目不将“完全消除幻觉”或“准确读懂真实心情”作为已实现能力；效果以评测为准。

## 建议实现路径

先做单角色、中文、文本对话原型，使用合成玩家数据和模拟天气；打通可评测闭环后接入真实模型与天气服务。首个里程碑是“可运行的角色对话与固定评测集”，详见实施计划。当前仓库没有可运行程序或安装步骤。
